# minh anh.ng — portfolio starter

Responsive HTML/CSS starter based on the portfolio details discussed in chat.

## Before publishing
- Replace `din.epost@example.com` in `index.html` with your email.
- Add your own CV PDFs to `assets/` named `cv-svenska.pdf` and `cv-english.pdf`.
- The project covers are temporary CSS-built visuals. Replace them with exported images from Figma if desired.
- Check all project descriptions and tags to ensure they accurately reflect your work.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, e.g. `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Use the published URL shown in the Pages settings. For a repository called `portfolio`, it is usually `https://YOUR-USERNAME.github.io/portfolio/`.

This starter uses responsive CSS: project cards stack on mobile and navigation becomes a menu.
